# Memory service: issue-scoped fact retrieval

Step 5b extends the existing fact query with optional `issue_refs`, a list of up to 100 `owner/repo#number` references. The generated endpoint reference is [OpenAPI](http://localhost:8001/docs).

The query combines SCIP symbol matches with `user_report` facts whose `source_issue` matches one of those references. Repository matching is case-insensitive. Reports need no anchors; unrelated reports and other fact kinds are not selected by issue reference. Duplicate facts are removed before applying the existing ancestry, closure, decay, first-parent TTL and limit rules. Omitting `issue_refs` retains symbol-only retrieval. No new table or configuration is introduced.

## R2 history ingestion repair

Git diff bodies can contain non-UTF-8 fixture data in historical sqlparse commits. The hunk parser needs ASCII headers only, so diff body decoding replaces invalid bytes. Paths still come from the separate NUL-delimited byte stream and retain their existing decoding. A regression test covers a Python change alongside legacy-encoded fixture text.

## Bounded R2 bootstrap

`Repo.bootstrap(base)` is an operator operation to run inside Memory with GitHub polling stopped. It batch-inserts missing, real commit ancestry metadata, then computes symbol diffs only for the selected base. SCIP loads the base and its immediate parents; new pushes continue through the normal push endpoint.

The `commits.symbols_indexed` boolean distinguishes metadata-only history from computed diffs. Old rows default to indexed. An unindexed row's empty diff arrays are placeholders, and `Commit.symbols_vs` raises rather than treating them as evidence of no code changes. Full `Repo.replay` upgrades these rows with real diffs; metadata bootstrap never overwrites indexed rows. Upgrades retain the original commit valid time.

After a successful bounded bootstrap, the operator acknowledges its returned head in the GitHub service's owned `memory_push_head` cursor before restarting polling. This keeps the default push endpoint's full-history behavior intact while giving R2 a bounded initial baseline. Historical invalidation outside the indexed window remains unverified until replay computes its diffs. No eval metrics are generated by bootstrap.
